# 학생회 근무표 메이커

에브리타임 시간표 캡처를 올리면 수업 시간을 읽어서, 행사 타임마다 수업이 겹치지 않는 학생회원을 고르게 배치한 근무표를 만들어 줍니다.

- 시간표 인식과 배치는 모두 브라우저 안에서 처리합니다. 사진은 어디에도 업로드되지 않습니다.
- 이름·수업 시간·설정은 사용하는 브라우저에만 저장됩니다.

## 파일

- `index.html`: 페이지 본문 (claude.ai 아티팩트로도 게시)
- `build.sh`: `index.html`을 GitHub Pages용 완성 문서 `docs/index.html`로 감쌉니다
- `docs/`: GitHub Pages가 서비스하는 폴더

`index.html`을 고친 뒤에는 `./build.sh`를 실행하고 `docs/`까지 함께 커밋하세요.
